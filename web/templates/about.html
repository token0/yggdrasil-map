About

yggdrasil-map v{{ version }}

This is a project that aims to demystify what the Yggdrasil network is like. The full source code of this version is at github.com/token0/yggdrasil-map, a fork of Arceliar/yggdrasil-map.

Network map

The map is built from the peering graph as seen from this site's own Yggdrasil node: starting from that node, every reachable node is asked for its peers. Nodes that do not answer such requests, and nodes reachable only through them, are missing, so the map is never complete.

The initial view shows a backbone tree: one link per node, chosen breadth-first from the best-connected node, so it follows the shortest hop paths. Every drawn link is a real peering, but the tree is computed here; it approximates, and is not, Yggdrasil's own spanning tree, whose parent links the network does not expose. Selecting a node shows all of its peer links, and faintly the links of its peers.

Node names come from the "name" field in NodeInfo. Dot size follows the number of peers. Colour follows either the peer count or the address height, the number of leading zero bits of the node's public key, which is encoded in the last two hex digits of the address's first group (e.g. 21e: is height 30).
