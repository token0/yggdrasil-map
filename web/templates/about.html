About

yggdrasil-map v{{ version }}

This is a project that aims to demystify what the Yggdrasil network is like. The full source code of this version is at github.com/token0/yggdrasil-map, a fork of Arceliar/yggdrasil-map.

Network map

The map shows the peering graph of the network as seen from this site's own Yggdrasil node: starting from that node, every reachable node is asked for its peers. Nodes that do not answer such requests, and nodes reachable only through them, are missing, so the map is never complete. With the lookups collector it instead shows the spanning tree as seen by the node.

Node names come from the "name" field in NodeInfo. Dot size follows betweenness centrality; colour follows either the peer count or the address height, the number of leading zero bits of the node's public key, which is encoded in the last two hex digits of the address's first group (e.g. 21e: is height 30).
